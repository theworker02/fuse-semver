# fuse-semver

Fuse timestamps and semver durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/fuse-semver/

## Install / run

```bash
git clone https://github.com/theworker02/fuse-semver.git
cd fuse-semver
node src/cli.js
node --test
```
